如何分享成手機網址？
  1. 下載最新 HTML，檔名改為 index.html。
  2. GitHub 建立儲存庫，上傳 index.html。
  3. 進入 Settings → Pages，Source 選 Deploy from a branch，選 main 與 / (root)，儲存。
  4. 部署完成後，把 GitHub Pages 提供的網址傳給家人。

公開網站會公開包含的行程與住宿位置；如果不想公開，可直接傳HTML檔案。網站上的每個瀏覽器仍各自儲存修改，並非多人即時共編。

若使用 Claude，可把 HTML 上傳並請它在 Artifact 中顯示；能否直接執行及分享，以該服務當時功能與權限為準。
